## App Actions

Each app can be presented in the web interface with:

* **Save the App**
* **Install App Preview**
* **Download Package**

Example:

```text
┌──────────────────────────────────────────────┐
│ Animal Sounds                                │
│ com.smartbabyapps.animalsounds               │
│ Version 2.0                                  │
│ iOS 3.1                                      │
│ 19.8 MB                                      │
│                                              │
│ [ Save the App ]                             │
│ [ Install App Preview ]                      │
│ [ Download Package ]                         │
└──────────────────────────────────────────────┘
```

## Archive Structure

The individual IPA packages use the following archive layout:

```text
Animal Sounds 2.0.ipa
└── Payload/
    └── Animal Sounds.app/
```

For example:

```text
SoundTouch 1.4.ipa
└── Payload/
    └── SoundTouch.app/

Tozzle 3.7.ipa
└── Payload/
    └── Tozzle.app/

Michigan Nature Sounds 1.0.ipa
└── Payload/
    └── Michigan Nature Sounds.app/
```

## GitHub Pages

This project can be hosted as a static website using GitHub Pages.

Recommended repository structure:

```text
app-store/
├── index.html
├── README.md
├── style.css
├── script.js
├── apps/
│   └── apps.json
├── assets/
│   ├── icons/
│   └── screenshots/
└── downloads/
    └── App Store.zip
```

## GitHub Codespaces

The project is also suitable for GitHub Codespaces.

Open the repository in Codespaces, edit the HTML/CSS/JavaScript files, and preview the static App Store interface.

## Notes

The metadata above describes the archive entries used by this example web application. Availability, installation behavior, and compatibility depend on the actual IPA files, signing status, device, and iOS version.

This project is intended as an archive/catalog interface. Only distribute application packages for which you have the appropriate rights or permission.
